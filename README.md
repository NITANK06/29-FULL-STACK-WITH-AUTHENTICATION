# 29-FULL-STACK-WITH-AUTHENTICATION

A complete full-stack authentication application built using React, Node.js, and Express.js.

**** project includes****

User Registration
User Login
JWT Authentication
Protected Routes
Token Management
User Profile Page
Features
Secure user authentication
Password hashing using bcrypt
JWT token generation
Protected frontend routes
Authentication middleware
User profile page
Persistent login using localStorage
Full-stack frontend-backend integration

**Technologies Used**

**Frontend**

React
React Router DOM
Context API
Fetch API
CSS3

**Backend**

Node.js
Express.js
JWT Authentication
bcryptjs
dotenv
CORS 


**Database****
MongoDB
